录制页 v2 设计定稿(与实现逐条对齐)

  1. 职责收窄: 本页只盯「进行中」——概览胶囊(进行中 / 本次已录 / 磁盘可用, 磁盘低于阈值 2 倍转红) + 进行中大卡 + 空态; 历史/回看/合并/删除全部归属视频库页, 本页不再放历史区与跳转入口。
  2. 大卡片 4 区: 直播封面头像(无封面回退昵称首字; 回放用琥珀相位) + 信息列(昵称/类型章/自动章/标题/工作路径) + 指标三连(时长·直播红回放琥珀 / 已写入(直播=段数, 回放=单文件) / 实时码率(Mbps·回放 MB/s)) + 操作(直播=停止, 回放=取消下载, 目录)。
  3. 底部进度带: 直播=不确定态流光(分段信息 + 磁盘告警), 回放=确定性比例条(百分比 + 已下载时长/估算全长)。
  4. 码率不耗请求: 复用 2s 任务推送做字节差分。
