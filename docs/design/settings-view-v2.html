v2 设计说明(审阅用)

  1. 治"空": 内容列宽放开(取消 640 上限); 开关项从长条行改为双列/三列磁贴, 同屏信息密度翻倍; 分区标题移出卡片(Linear 式), 卡片只装内容。
  2. 治"不协调": 图标单色化——左侧导航图标全部 ink3 灰, 仅激活项品牌粉; 废除此前红/蓝/黄/绿/紫五色图标块。
  3. 统一 chip 语言: 全稿只有一种标签规格(22px 高/7px 圆角/11px 半粗), 语义色仅 4 种: 品牌粉/成功绿/警告琥珀/中性灰; 版本号、脏状态、更新结果全部套用。
  4. 关于区品牌化: 粉色渐变横幅 + Joftal 的 GitHub 头像灰度水印(grayscale, 离线自动隐藏); 元信息两格(制作 Joftal / 仓库); GitHub 按钮用官方深黑增强识别, 检查更新用品牌粉区分主次。
  5. 吸底操作条悬浮化: 毛玻璃圆角浮条, 不再是贴底分割线, 与整页卡片语言一致。
  6. 保留全部功能行: 不新增/删减任何设置项, 纯 UIUX 层改造。
