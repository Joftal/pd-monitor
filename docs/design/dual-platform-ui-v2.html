2. 六条原则（本稿全部可验证）

P3 原案"卡片左侧色轨"已按可读优先撤下，理由见下

P1 · 一个身份只有一个出口

同一屏内平台信息出现次数 ≤ 1。筛选器已限定平台时（platFilter !== 'all'），卡片上的徽标是纯噪音，直接不渲染。

P2 · 徽标 = 文字 + 色点，永不只有颜色

识别由 SOOP / PandaLive 文字承担，色点只是余光强化。色觉障碍、截图灰度打印、深色主题下都不失效。这也是撤掉"色轨"的原因：3px 竖条是无文字编码，一旦作为唯一区分就违反本条。

P3 · 形状随承载面，不随平台

图片上 = 墨底白字，卡面上 = 浅底墨字。两档只差承载面底色，文字/圆角/字号完全一致。不再为 SOOP 单独造一套深色贴纸。

P4 · 一个控件一个长相

"选平台"在监控墙 / 录制 / 视频库 / 账号 / 弹窗里必须是同一个 PlatFilter，同高度同边框同选中态。

P5 · 平台边界用徽标说，不用长句说

"检测模式(仅 PandaLive)" → 检测模式 + PandaLive 小徽标；说明句里"SOOP 恒为逐频道探针"这类补充保留，但只在 tooltip / 次级文案，不进标题。

P6 · 大厅是单平台页，就别装作是双平台页

大厅只聚合 PandaLive（本期决策），却给 241 张卡各挂一枚 PandaLive 徽标 —— 这是当前最大的一处重复。改：页头挂一枚，卡片不挂。

3. 可读优先的红线（本稿不越界的地方）

  • 不缩小正文字号。标题 13.5px / 昵称 12px / 元信息 11.5px 一律不动，只减重复元素，不压信息密度。
  • 不把"SOOP"缩成图标。曾用过 S 单字母方案，实测在 11px 下与 5、s 难分，且失去搜索可读性 —— 撤下，只保留在顶栏头像（那里有 tooltip 且是账号语义，不是数据语义）。
  • 不靠颜色区分在播/离线。状态继续由文字徽标（直播中 / 已下播）承担。
  • SOOP 卡片不补假数据。无单频道人数接口（实测），统计列继续整列不出现，而不是显示 0 —— 0 会被读成"没人看"。

2. 为什么"墨底白字 + 色点"而不是"品牌色底 + 白字"

对比度实测

白字压 #fb7299 只有约 2.9:1，11px 粗体在 1080p 上偏糊；粉字压白约 3.0:1，同样在临界。
白字压 rgba(17,19,24,.74) 约 13:1，墨字压 #f4f5f7 约 16:1 —— 两档都远超正文要求。
结论：底色选深/浅中性，平台色只留给 6px 圆点，可读性优先于品牌色铺陈。

深色主题下的行为

onimg 档不变（本来就压在图片上）。onsurf 档底色走 --fill 变量，自动变成 #262629，文字走 --ink1 自动变浅 —— 组件不需要写 dark: 分支，这是它比现状 4 套硬编码色值更稳的地方。

3. 组件签名（落地时照此实现）

template: <span class="pt [size] [surface] [p|s]"><i class="dot"/>{{ platform === 'soop' ? 'SOOP' : 'PandaLive' }}</span>

// src/renderer/src/components/PlatFilter.vue
props: { modelValue: 'all'|Platform; counts?: Record<string, number>; showAll?: boolean }
emits: 'update:modelValue'  ·  内部复用 PlatTag 的色点，保证 chip 与徽标同源

为什么大厅的徽标可以整列删掉

  • 大厅数据源写死 platform: 'pandalive'（ExploreCard 第 21 行），结构上不可能出现 SOOP 卡 —— 徽标信息量为 0。
  • 删掉后缩略图左上角只剩「直播中 / REC / 源就绪」，这三个才是用户扫卡时真正要比较的维度。
  • 页头那枚 PandaLive 徽标 + 右侧「SOOP 房间请在已关注粘贴地址」把"这个 tab 是谁的"说清楚，同时补上了当前缺失的跨 tab 指引（新用户找不到 SOOP 入口）。
  • 搜索 placeholder 由「搜索 PandaLive 主播 / 标题」改「搜索大厅主播 / 标题」：搜索本来就只作用于大厅（keyword 会强制跳 explore），"PandaLive" 三字在这里是误导 —— 用户会以为它能搜 SOOP。
唯一需要小心的连带改动：LiveCard 是 大厅 / 已关注 / 播放页 共用组件。徽标必须做成 showPlatform 开关（默认 true，大厅传 false），不能直接删模板 —— 否则已关注墙失去唯一的常驻平台标记。
